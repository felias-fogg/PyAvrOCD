Name PoC only Start of Dev. Platforms Interfaces MCUs Debug Probes Comment
AVaRICE 2001 Mainly POSIX (Linux), but by now also Mac & Windows (C++) JTAG, dw, PDI classic ATtiny & ATmega, Xmegas all, but the most recent MPLAB probes (5 series) First AVR GDB server ever. Support used to be more active.
dwire-debug Yes 2017 Cross-platform (C) dw ATtiny13, 84, 841, 45, 85,
ATmega168PA, 328P, and perhaps similar		 only USB-UART bridge and a bit of hardware Minimal implementation, only one BP, based on reverse engineering of debugWIRE protocol
debugwire-gdb-bridge ? 2018 Cross-platform (Pascal) dw ATtiny 13, 2313, 24, 44, 84, 25, 45, 85, 441, 841
ATmega48, 88, 168, 328		 USB-UART bridge and a bit of hardware Based on dwire-debug, but much more complete
dwtk 2019 Linux (Go) dw all dw targets only USB-UART bridge and a bit of hardware Full server. Tested coverage unclear.
pyAVRdbg Yes 2020 Cross-platform (Python) UPDI ATmega4809, AVR128DA48, probably more All EDBG-based debuggers HW and SW breakpoints, no flash programming
dw-link 2021 Cross-platform (Arduino firmware) dw all dw targets runs on Arduino UNO Provides RSP interface over serial line, based on dwire-debug and DebugWireDebugger AndProgrammer
Bloom 2021 Only Linux (POSIX, C++) JTAG, dw, PDI, UPDI classic ATtinys & ATmegas, Xmegas, all modern parts All EDBG-based debuggers Best in terms of chip coverage.
pyavrdebug Yes 2022 Cross-platform (Python) UPDI some modern parts All EDBG-based debuggers Only 2 breakpoints, no flash programming, based on pymcuprog
gdb-debug-wire-integrated-server Yes 2022 Cross-platform (Arduino firmware) dw ATmega328P, ATTiny85 Implemented on ATmega32U2 or ATmega16U2 Provides RSP interface over serial line; in addition a RTT line; can be flased on a 16U2 on an UNO board
updi-gdbserver Yes 2023 Cross-platform (Scheme) UPDI some modern parts USB-UART bridge Written in Scheme, only two breakpoints, based on reverse engineering of UPDI protocol
PK5-UPDI-GDB-Server 2024 Cross-platform (Python) UPDI all modern parts PICkit 4/5 Only two hardware breakpoints, based on reverse engineering of USB protocol
dw-gdbserver 2025 Cross-platform (Python) dw All dw targets All EDBG-based debuggers & dw-link Based on pymcuprog
PyAvrOCD 2025 Cross-platform (Python) JTAG, dw All classic ATtinys & ATmegas All EDBG-based debuggers & dw-link Successor of dw-gdbserver, based om pymcuprog
